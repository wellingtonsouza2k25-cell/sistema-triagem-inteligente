# Registro de Riscos — Sistema de Triagem Inteligente

| Risco | Chance | Impacto | O que faremos |
|---|---|---|---|
| Dificuldade em desenvolver a versão web | Alta | Alto | Estudar a tecnologia escolhida e desenvolver uma funcionalidade por vez. |
| Falta de participação de algum integrante | Média | Alto | Distribuir responsabilidades e acompanhar as tarefas no Trello. |
| Problemas na integração com a API Gemini | Média | Alto | Testar a integração separadamente e tratar falhas sem classificar automaticamente como baixa urgência. |
| Perda ou inconsistência dos dados no banco | Média | Alto | Realizar testes de gravação e consulta e manter cópias de segurança durante o desenvolvimento. |
| Atraso no desenvolvimento das funcionalidades | Alta | Alto | Definir responsáveis, acompanhar as datas no Trello e priorizar as histórias essenciais. |
